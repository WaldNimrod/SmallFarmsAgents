## 8. החלטות UX שצריך לנעול

1. האם הציבורי הוא עמוד אחד עם אזור benchmark, או שני עמודים נפרדים
2. האם public page יציג טבלה בלבד, או גם כרטיסים
3. האם נרצה sparkline קטן לכל מוצר
4. האם benchmark יוצג ב-toggle או tab
5. האם נסביר מתודולוגיה בעמוד עצמו או בעמוד נפרד

## 9. המלצה UX

### ציבורי

- עמוד אחד
- אזור ראשי לשוק הקהילתי
- אזור benchmark מתקפל או tab נפרד
- טבלת מוצרים + כרטיס מוביל אחד או שניים

### admin

- layout דו-עמודי פשוט
- ניווט צד
- טבלאות ברורות
- כפתור publish ברור
