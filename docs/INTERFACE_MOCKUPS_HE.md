# מוקאפ ממשקים

גרסה: 1.1  
תאריך: 2026-03-29  
שינויים מגרסה 1.0: הסרת פילטר region, הוספת stale data banners, הוספת Normalizer admin מסך, עדכון tabs ציבוריים

## 1. הערות כלליות

- אלו מוקאפים פונקציונליים ולא עיצוב סופי
- הממשק הציבורי צריך להרגיש כמו חלק טבעי מ-`nimrod.bio`
- הממשק המקומי יכול להיות utilitarian ופשוט
- **region filter הוסר מ-V1** — לא יוצג בממשק

## 10. החלטות UX — גרסה v1.1

| שאלה | החלטה |
|---|---|
| הציבורי — עמוד אחד או שניים? | עמוד אחד עם tabs |
| benchmark — toggle או tab? | tab נפרד |
| סלים — tab נפרד? | כן — "סלים ו-CSA" |
| region filter? | **לא בV1** |
| sparkline / גרף מגמה? | כן — minimal בכרטיס מוצר |
| מתודולוגיה — עמוד נפרד? | כן — tab "איך אנחנו מחשבים?" |
| staleness banners? | כן — warning צהוב (3d), stale אדום (8d) |
| distinct_sources בציבורי? | כן — "ממקורות: N" בכל מוצר |

## 11. המלצה UX סופית

### ציבורי

- עמוד אחד
- **tabs:** שוק קהילתי | סלים ו-CSA | השוואה לרשתות | איך אנחנו מחשבים
- staleness banner אם נדרש — מעל ה-tabs
- כרטיסי מוצר + טבלה קריאה
- updated_at תמיד גלוי

### admin

- layout דו-עמודי: ניווט צד שמאל, תוכן ראשי ימין
- tab ניווט: Dashboard | Sources | Runs | Observations | QA | Publish | Normalizer
- טבלאות ברורות עם filter
- כפתור publish ברור ב-Dashboard
