## 3. Acceptance criteria (numbered, testable)

### Item 1 — price-chip (+ estimated)
- **AC-1.1** A crop with a **live** product price (resolved by crop slug OR `crops.hebrew_name = products.hebrew_name`)
  renders the chip as today: `בשוק <₪price>/<unit>`. (Built — see §4.1; route test exists.)
- **AC-1.2** A crop with **no** live product price **but** a `payload.market_link.price_current > 0` renders an
  **estimated** chip: distinct label **`מחיר מוערך`** (NOT `בשוק`), e.g. `מחיר מוערך ₪<price>/ק״ג`, visually
  differentiated (muted/dashed) so it reads as an estimate, not live.
- **AC-1.3** A crop with neither renders **no** chip (honest — never fabricated).
- **AC-1.4** Priority is strict: live price wins over the book estimate; estimate wins over nothing.
- **AC-1.5** Route tests: (a) live chip renders `בשוק` for a hebrew-name-linked product (exists); (b) estimate chip
  renders `מחיר מוערך` for a crop with `market_link.price_current` and no product; (c) no chip when neither.

### 9.1 — AC-1.2 REDEFINED: estimate is a render-side **infrastructure**; the data comes from a team_80 WP (F-190-TAILS-S-01, MAJOR)
**Root cause confirmed:** there is **no stored book-estimate price**. `market_link.price_current` is computed **live**
in `bookCrop()` (`CropBookViewController.php:578-588`, `SELECT last_price FROM products WHERE slug = ?`) and is **never**
persisted to `crops.payload_json`. The crop-book **list** chip is driven by `entry()` (L195+ `$priceBySlug`), a different
route. So v1.0.0's "extract `payload.market_link.price_current` in `entry()`" is unbuildable — that key does not exist.

**team_00 decision (2026-06-12):** build the **render-side infrastructure** now; the estimate **data** (current price
ranges + units) is gathered by a separate **team_80 market-research WP** (`SFA-S003-P004-WP-CB-MARKET-RANGES`, registered
2026-06-12; brief `_COMMUNICATION/team_80/SFA-S003-P004-WP-CB-MARKET-RANGES/MISSION_2026-06-12_v1.0.0.md`).

**AC-1.2 (revised) — render contract (this WP, render-layer only):**
- `entry()` reads an optional per-crop payload key **`market_estimate`** with shape:
  `{ "price_min": <float>, "price_max": <float>, "unit": "<he, e.g. ק״ג>", "source": "<short>", "as_of": "YYYY-MM" }`.
- **Priority (strict):** live product price (AC-1.1, slug-OR-`hebrew_name`) **>** `market_estimate` (AC-1.2) **>** no chip (AC-1.3).
- When a crop has **no** live price **and** a valid `market_estimate` (`price_min > 0`), render the **muted/dashed**
  `.cc__price--est` chip: `מחיר מוערך ₪<min>–₪<max>/<unit>` (collapse to `₪<v>/<unit>` when `min == max`). Honest-omit otherwise.
- **`market_estimate` is empty in production until team_80 delivers** — so the chip simply does not render yet (honest,
  AC-1.3). The build proves the infrastructure with a **seeded test fixture** crop carrying `market_estimate` + no product.
- **Scope guard:** this WP only READS `market_estimate`; it does NOT define a schema column or populate data (that is the
  team_80/data WP). Reading an optional `payload_json` key is render-layer.
