# LOD300 — ספר גידולים: מוקאפ ממשק

> **מה מאשרים כאן:** מבנה המסכים, היררכיית הניווט, ואילו שדות מוצגים איפה. לאחר אישור → LOD400 (spec מפורט לbuilder). זהו ממשק **צפייה בלבד** — ללא עריכה.

## עקרונות ממשק

| עיקרון | הגדרה |
|--------|-------|
| **שפת UI** | עברית. RTL. מושגים מקצועיים = עברית עם אנגלית בסוגריים |
| **היררכיה** | קטגוריה → גידול → זן |
| **multi-source** | תמיד ניתן לראות "מה JMF אמר" vs "מה החווה מדווחת" |
| **המרת יחידות** | כל ערך בצרור/חבילה מציג גם ק"ג שקול |
| **view-only** | S003 = קריאה בלבד. עריכה / הוספה = S004 |

## מפת ניווט

```
ספר גידולים (רשימה + פילטור)
    │
    ▼
עמוד גידול
    ├── TAB: זנים         ← רשימת זנים + סיכום כלכלי
    ├── TAB: נתוני שדה    ← DTM, יחידות, תשואה מוצגת לפי מקור
    └── TAB: ציוד         ← הגדרות מזרע (מוצג רק אם קיים)
         │
         ▼
    עמוד זן
         ├── toggle מקור: מאוחד / JMF / חווה נימרוד
         ├── פרמטרי שתילה
         ├── נתוני תשואה ומחיר
         ├── טבלת מקורות (side-by-side)
         └── ציוד (אם קיים)
```
