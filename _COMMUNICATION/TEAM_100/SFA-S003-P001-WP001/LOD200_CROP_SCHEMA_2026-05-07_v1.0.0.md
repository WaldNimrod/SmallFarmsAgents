## §4.5 — טבלה 4: `זן_ערכי_מקור`

**עיקרון:** "אנחנו תמיד שומרים מה כל מקור טוען ונציג גם מאוחד וגם בנפרד" (team_00, 2026-05-07).

כל שדה כמותי בטבלת `זנים` מייצג **ערך מאוחד** (ברירת מחדל לתצוגה). טבלה זו שומרת את הערכים הגולמיים **לכל מקור בנפרד**, כולל סתירות.

| שדה | טיפוס | nullable | הערה |
|-----|-------|----------|------|
| `id` | uuid PK | לא | |
| `זן_id` | fk → זנים | לא | |
| `שם_שדה` | text | לא | שם השדה ב-`זנים` (למשל: `תשואה_ממוצעת_למ_ערוגה`) |
| `מקור` | text | לא | `JMF` / `Tend_2022` / `Tend_2021` / `ידני` |
| `ערך_טקסט` | text | כן | ערך גולמי כמחרוזת (מספרים + טקסט) |
| `ערך_מספרי` | numeric | כן | ערך מספרי אם parseable |
| `יחידה` | text | כן | `ק"ג/מ'` / `₪/צרור` / `ימים` וכו' |
| `הערה` | text | כן | הקשר: `"שורה 47 CROP_PLAN 2022"` |

**שימוש:** ה-importer מאכלס תחילה את `זן_ערכי_מקור`, לאחר מכן סקריפט reconciliation בוחר ערך ל-`זנים` (Tend מועדף לתשואה/מחיר; JMF מועדף ל-DTM/ריווח). כל ערך ב-`זנים` ניתן לעקוב עד לשורת המקור.

**דוגמה (ארוגולה):**

## §4.7 — טבלה 6: `המרות_יחידות`

כל שורה = המרה מיחידת מכירה → גרם, לקבוצה **או** לגידול ספציפי.

**עיקרון:** גידול ספציפי גובר על קבוצה. תמיד ניתן להמיר בין כל יחידות הגידול דרך גרם כ-pivot.

| שדה | טיפוס | nullable | הערה |
|-----|-------|----------|------|
| `id` | uuid PK | לא | |
| `קבוצת_המרה_id` | fk → קבוצות_המרה | כן | null אם שורה ספציפית לגידול |
| `גידול_id` | fk → גידולים | כן | null אם שורה ל-קבוצה |
| `יחידת_מקור` | text | לא | `צרור` / `מארז` / `ראש` / `ק"ג` |
| `יחידת_יעד` | text | לא | `גרם` *(pivot אחיד)* |
| `ערך_המרה` | numeric | לא | גרמים ליחידה אחת |
| `הקשר` | text | כן | `טרי` / `ארוז` / `הידרו` |
| `מקור` | text | לא | `team_00` / `JMF` / `ידני` |

**אילוץ:** בדיוק אחד מ-`קבוצת_המרה_id` / `גידול_id` חייב להיות מאוכלס (לא שניהם ריקים, לא שניהם מלאים).

## §4.8 — מדיניות מקור DTM

**סדר עדיפות ב-`ימים_לבשלות` (שדה מאוחד ב-`זנים`):**

1. `team_00` — ידע ישיר מהחווה, ישראל-ספציפי **(עדיפות עליונה)**
2. `JMF` — MasterClass, בנצ'מרק קנדי-מקצועי
3. `Tend` — CROP_PLAN בפועל (ריק ברוב הגידולים, outlier-prone)

כל ערך DTM — מכל מקור — נשמר ב-`זן_ערכי_מקור`. השדה המאוחד = ערך מהמקור בעל העדיפות הגבוהה ביותר שקיים.

**כלל outlier importer:** DTM Tend < 20 ימים לארוגולה/עלים בייבי → דחה + log ב-`זן_ערכי_מקור` עם flag.

**דוגמה — ארוגולה:**

| מקור | ערך | עדיפות | נשמר ב |
|------|-----|--------|--------|
| team_00 | 21 ימים (ישראל קיץ) | 1 — **מאוחד** | `זנים.ימים_לבשלות` + `זן_ערכי_מקור` |
| JMF | 30–40 ימים | 2 | `זן_ערכי_מקור` בלבד |
| Tend_2022 | 8 ימים (outlier) | 3 — נדחה | `זן_ערכי_מקור` עם flag |
