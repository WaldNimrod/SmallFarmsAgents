> **מה מאשרים כאן:** את ה-schema המלא — שלוש הטבלאות, שמות השדות בעברית, ערכי ה-enums, ומיפוי המקורות. אחרי אישור זה מתחיל WP-S003-2 (seed נתונים) ו-WP-S003-3 (UI). שינוי schema לאחר מכן = migration + UI refactor.

## §1 — עקרונות מנחים

| עיקרון | הגדרה |
|--------|-------|
| **שפת DB** | עברית לכל ערך טקסטואלי. חריגים: שמות מדעיים (לטינית), שמות ציוד (אנגלית) — מסומנים במפורש |
| **היררכיה** | משפחה בוטנית → גידול → זן (3 טבלאות; פרמטרים מדויקים תמיד ברמת הזן) |
| **מקור נתונים** | כל ערך נושא שדה מקור: JMF MasterClass / Tend חווה נימרוד / שניהם / ידני |
| **שדות חסרים** | כל שדה nullable — גידול עם נתונים חלקיים הוא מצב לגיטימי |
| **scope** | כל גידול מכל מקור נכנס (כולל עצים ופירות). **לא נכנסים:** סלים, ביצים |
