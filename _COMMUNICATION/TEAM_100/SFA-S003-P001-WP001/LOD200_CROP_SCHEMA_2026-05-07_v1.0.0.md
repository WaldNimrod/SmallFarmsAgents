## §1 — עקרונות מנחים

| עיקרון | הגדרה |
|--------|-------|
| **שפת DB** | עברית לכל ערך טקסטואלי. חריגים: שמות מדעיים (לטינית), שמות ציוד (אנגלית) |
| **היררכיה** | משפחה בוטנית → גידול → זן (3 טבלאות; פרמטרים מדויקים תמיד ברמת הזן) |
| **מקור נתונים** | כל ערך נושא שדה מקור: JMF MasterClass / Tend חווה נימרוד / ידני |
| **שדות חסרים** | כל שדה nullable — גידול עם נתונים חלקיים הוא מצב לגיטימי |
| **scope** | כל גידול מכל מקור נכנס (כולל עצים, פירות, גידולי כיסוי). **לא נכנסים:** סלים, ביצים |
| **זן ברירת מחדל** | הזן הנפוץ ביותר בישראל; אם לא ברור — לשאול team_00 |
