### Existing WordPress integration pattern (DO NOT REINVENT)
```
PublishEngine (Flask/Jinja2)
  → renders public_report_body.html (fragment, no header/footer)
  → saves to output/public/

  → sfagent-manifest-of-urls.json pointer file → WP option sfagent_manifest_of_urls_url
  → WordPress page shortcode [sfagent_market_report]
      → fetches manifest → dereferences report_body URL → returns HTML
  → child theme sfagent-base.css enqueued on pages with shortcode
```
