## 0. Why
The market **detail** page `/market/{slug}` (`market_product.php`) is the last surface still on the **old Class-B v2
design** (`.pbig`/`.pgraph` + heavy inline styles + raw OS emoji), while the market **list** + crop pages moved to
the redesign DS in WP-CB-UI-MOCKUP-FIDELITY. It also carries the DSX1-SWEEP-excluded emoji-fold and the 2 disabled
range buttons. This WP brings the detail page into the same design language.

## 1. Scope
1. **Re-skin** `/market/{slug}` to the redesign DS — match the market-list drill-down visual language
   (`.pcard`/`.pc__*` price card + `.fresh`/`.spark`/`.bigspark` + `redesign.css` tokens), replacing the inline-styled
   `.pbig`/`.pgraph`/`.pstats` Class-B v2 blocks.
2. **Emoji-fold** — replace raw OS emoji (`📦` 126, `📊` 205, `📭` 197/264, `📖` 343) with DSX-1 line-glyphs (`.gi` +
   the `ui-icons.svg` sprite), consistent with the rest of the redesign.
3. **Range-selector disposition** — the `90י`/`שנה` buttons are disabled `בקרוב` (no 90-day/yearly data). Decide:
   keep honestly-disabled, or remove until the data exists (default: keep disabled with `בקרוב`, or remove — team_35/00 call).
4. **Watercolor hero** — use the product's watercolor (via `CropArt`, resolved through the crop slug as on the list)
   in the price hero instead of the single-letter glyph (`.pbig__art` `veg` letter today).

## 2. Non-goals
- No new data / no price-history changes / no schema. Render-layer only.
- No 90-day/yearly graph implementation (no data) — only the button disposition.
- No market-list changes (already at parity).

## 3. Acceptance criteria
- **AC-1** `/market/{slug}` renders in the redesign DS: capped `.shell` (1100px), redesign tokens/spacing/radii, the
  price card + freshness pill + sparkline + 28-day graph + history table styled to match the market-list drill-down
  and the crop pages. No inline-styled Class-B v2 blocks remain for the primary content.
- **AC-2** Zero raw OS emoji in `market_product.php`; all icons are DSX-1 `.gi` glyphs.

  (set by the shared `MarketViewController::mapProductRow()` at L260 via `CropArt::file($bookSlug)`, called by both
  `index()` and `detail()`); line-glyph fallback when `wc_art` is empty/unmapped. **Template-only** — no controller
  change (see §4 + §8).
- **AC-4** Freshness pill uses the redesign `.fresh.f/.a/.s` (consistent with the list); the 28-day graph + history
  table are preserved (data contract unchanged) and styled to DS.
- **AC-5** The `90י`/`שנה` buttons are resolved per the §1.3 decision (kept-disabled-`בקרוב` or removed) — no broken
  affordance.

## 4. File-level design
- `templates/pages/market_product.php` — rebuild the markup to the redesign DS: replace `.pbig`/`.pgraph`/`.pstats`
  inline-styled blocks with `.pcard`/`.pc__*` + redesign component classes; fold emoji → `.gi` glyphs; wire the
  watercolor `<img>` into the hero by consuming the **already-present** `$product['wc_art']` (the page currently
  renders the `veg`-letter glyph / `📦` at L126 instead). The emoji to fold: L126 `📦`, L197 `📭`, L205 `📊`,

  on `$product` by the shared `mapProductRow()` (L260/L261), which `detail()` calls at L86 — same path as `index()`
  (L63). The v1.0.0 "add `wc_art` to `detail()` / mirror `index()`" instruction was inaccurate and is retracted (§8).
- `public_assets/css/redesign.css` — add a `/market/{slug}` detail section (reuse list `.pcard`/`.pc__*`/`.fresh`/

  the now-unused `.pbig`/`.pgraph`/`.pstats`/`.pdetail` blocks from `classb.css`/`mobile-fixes.css` **only after**
  confirming no other surface uses them (include-gate, as in MOCKUP-FIDELITY).
- Keep the data contract (`MarketViewController::detail` → `$product`/`$history`) unchanged.
