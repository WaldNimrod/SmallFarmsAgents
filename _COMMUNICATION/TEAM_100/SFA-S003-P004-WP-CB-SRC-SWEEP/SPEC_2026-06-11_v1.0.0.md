### 3.2 L45 — IL farm 2017 base-data cherry-pick (crop #31 untouched; ~20 existing crops)

  (`days_to_maturity`, `spacing_in_row_cm`, `rows_per_bed`) on the default variety + one internal
  `growing_tip` note (season + cultural notes) per crop.
- **Excluded sheets** (documented in `scripts/extract_l45_basedata.py`): planting-calendar/plot-map
  (duplicates 197 existing calendar rows), prices (price-index domain), budget/garden-rentals (business),
  trees (perennials, out of annual-veg scope), and `ירוק` (**cannabis cultivation data** — out of scope).
- Trust tier OP / confidence 0.80 (NOT a hard override) — the reconciler outlier-rejects values that
  diverge from researched consensus (correct behaviour; many transplant→harvest DTM values rejected).

### 3.3 Robustness fix (unblocks the canonical seed)

  (mirrors `jmf_book`). Pre-existing re-seed drift (multiple null-name varieties per crop) was crashing
  `seed --all` with `MultipleResultsFound`.
