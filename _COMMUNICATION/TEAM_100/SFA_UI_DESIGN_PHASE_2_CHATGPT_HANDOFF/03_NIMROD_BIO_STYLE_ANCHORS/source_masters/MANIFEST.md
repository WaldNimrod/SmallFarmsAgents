## font_carmela/ (the brand typeface)
`carmela.ttf` + `CARMELA`/`CARMELA REGULAR` + `CARMELIT BOLD`/`CARMELIT REGULAR`
+ `subset-Carmela.ttf`. This is the Hebrew display font of the "מהגינה של נימרוד"
wordmark. Use for any wordmark/lockup needs. **Never bake text into illustrations**
— but the brand wordmark, when needed in UI/print, uses Carmela.
