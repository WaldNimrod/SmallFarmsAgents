**Project:** SFA Visual System — חקלאות קטנה

**Purpose:** Define and generate a coherent, large-scale visual system for SFA, a
community platform for Israel's small-scale organic farming market
(https://sfa.nimrod.bio). The system covers brand/OG art, module hero images,
functional icons, UI textures/backgrounds, empty states, and community
illustrations.

**Two sources:**
- **Style source = the existing nimrod.bio illustration line** ("מהגינה של נימרוד")
  — soft watercolor vegetables, the basket, warm brown ink line, cream paper.
  We **continue this line**; we do not invent a new style.
- **Product source = the live SFA app** — defines slots, sizes, RTL, palette, gaps.

**House feeling:** delicate, pleasant, hinted, calm, quiet, handmade. A garden
journal — never a stock brochure, never generic AI watercolor.

**How we work:** first agree the style via a small **calibration set (6–8
images)**; only after approval do we produce families at scale, in phases.
Reference images are attached to the project — match them.
