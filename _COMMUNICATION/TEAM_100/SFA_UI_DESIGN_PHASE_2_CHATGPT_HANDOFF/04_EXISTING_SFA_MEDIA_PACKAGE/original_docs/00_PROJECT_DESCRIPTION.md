# SFA Media Studio — ChatGPT Project Description

> Paste this into the ChatGPT Project "Description" field (or keep as the
> project's pinned reference). Short, human-facing.

**Project name:** SFA Media Studio — חקלאות קטנה

**Purpose:** Generate the brand illustration set for **SFA (חקלאות קטנה)** — a
community platform for Israel's small-scale organic farming market
(https://sfa.nimrod.bio). Each chat session in this project produces **one**
media asset (a share image, a module hero, a section illustration, or the
favicon) in a single, consistent calm-craft watercolor style.

**What this project produces:** 12 numbered assets (1 Open Graph share image,
8 square module-card heroes, 2 wide section illustrations, 1 favicon set).
Filenames, dimensions, and byte budgets are fixed — see context file
`C3_ASSET_SPEC_TABLE.md`.

**House style in one line:** warm hand-illustrated watercolor + fine ink
linework on cream paper; muted earthy palette (leaf-green, tomato-red, sun-gold,
soil-brown); **no text inside the image, no photographs**. "The brand is calm."

**How to work it:** Upload the 4 context files (C1–C4) to the Project's files /
knowledge. Then open one new chat per asset and paste the matching numbered
prompt from the `prompts/` folder (SESSION_01 … SESSION_12). Generate, export to
the target spec, save to the named path.
