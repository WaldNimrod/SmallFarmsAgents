## The line, in words (matches C2 design system)
- Hand-painted **watercolor** with **warm brown/ink pencil linework**.
- **Cream paper** ground, visible texture; **muted, earthy** vegetable colors
  (olive/leaf-green, beet/tomato red, soil-brown, soft gold). Never neon, never glossy.
- Loose, confident, unhurried, slightly imperfect — handmade, not digital-clean.
- Subjects: vegetables, baskets, garden produce — the same family as the logo basket.

## How to use in a session
At the start of each image session, after the prompt, add: *"Match the watercolor
treatment, palette, paper texture, and hand-drawn line quality of the attached
reference images (especially ref_watercolor_radishes.jpg)."* This keeps the whole
new set on the existing nimrod.bio illustration line.
