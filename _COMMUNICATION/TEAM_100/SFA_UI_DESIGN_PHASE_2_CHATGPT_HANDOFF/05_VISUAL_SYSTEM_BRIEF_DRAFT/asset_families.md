# Asset Families — SFA Visual System

Each family has a distinct role, detail level, and style intensity. All share the
nimrod.bio DNA (cream paper, muted palette, watercolor + brown ink line, calm).

## 1. Brand / OG / wide illustrations
- **Role:** social share (OG), homepage hero, contact scene — the brand's "face".
- **Sizes:** OG 1200×630; wide heroes 1600×900 (16:9).
- **Style intensity:** HIGH (most painterly, richest). **Detail:** medium-high.
- **Color:** full muted palette. **Composition:** a scene with breathing room
  (desk/workshop, people+greenhouse, produce spread). Off-center, airy.
- **Subjects:** garden-planner desk, basket, produce spread, greenhouse, people.

## 2. Module hero images (×8)
- **Role:** per-card art (crop-book, market, calc, planner, clients, inventory, tend-bridge, field-log).
- **Size:** 800×800 (1:1, full-bleed cover; icon reverts to corner badge).
- **Style intensity:** MEDIUM. **Detail:** medium. **Color:** one accent per module + paper.
- **Composition:** ONE loose subject or small cluster per card, NOT a lineup.
  Vary across the 8 so the grid reads as a family, not repetition.
- **Subjects:** see `02_PRODUCT_UI_CONTEXT/module_definitions.md` per-module anchors.

## 3. Functional icons
- **Role:** nav/UI glyphs (extends `icons.svg`).
- **Size:** ~24px usable; design at 96–256px then simplify. **Style intensity:** LOW.
- **Detail:** minimal. **Color:** mostly line-art + optional minimal wash (per D09 rec B).
- **Composition:** single centered glyph, clean at tiny size. Match `ref_lineart_basket.png`.

## 4. UI textures / backgrounds
- **Role:** subtle section grounds (paper grain, faint wash bands).
- **Size:** tileable / large. **Style intensity:** VERY LOW (must not compete with content).
- **Detail:** near-flat. **Color:** paper tones only, very low contrast.
- **Composition:** abstract, edge-safe, seamless-ish. No recognizable objects.

## 5. Empty states
- **Role:** "no results", empty search, empty feed.
- **Size:** ~600–800px. **Style intensity:** LOW-MEDIUM. **Detail:** light.
- **Color:** muted, friendly. **Composition:** a small, gentle single object (empty
  basket, blank notebook page, a single sprout) with lots of space. Calm, not sad.

## 6. Community / contribution illustrations
- **Role:** community feed / contribution CTAs.
- **Size:** small-medium. **Style intensity:** MEDIUM. **Detail:** light.
- **Subjects:** hands sharing produce, a note being pinned, growers chatting.

## 7. Future module visuals
- **Role:** art for modules added later (seasonal tools, etc.).
- Reuse the hero family spec; same DNA. Placeholder family — defined when modules land.
