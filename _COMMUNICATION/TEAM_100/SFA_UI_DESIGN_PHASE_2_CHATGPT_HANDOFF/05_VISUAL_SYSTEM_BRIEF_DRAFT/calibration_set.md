## How to run calibration
1. One ChatGPT session per sample (or batched), anchors attached.
2. Export PNG; place in `candidates/` (versioned, per D08).
3. Lay all samples beside the anchors → judge against `qa_rubric.md`.
4. Nimrod approves / requests adjustment. **Do not start mass production until the
   calibration set is approved.**
