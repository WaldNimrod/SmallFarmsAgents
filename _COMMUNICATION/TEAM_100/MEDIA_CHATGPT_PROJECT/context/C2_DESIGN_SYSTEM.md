# C2 — Design System (palette · type · style language)

Extracted from the live stylesheet `gj.css` ("Garden Journal" direction) and the
team_35 design tokens. This is the binding visual SSoT for all generated media.

Saturation is **muted and earthy** throughout. No neon, no pure primaries, no
high-gloss. Whites are replaced by cream paper.

## Typography (FYI only — never rendered inside images)
- Headings: **Frank Ruhl Libre** (serif), Hebrew RTL.
- Body: Assistant / Heebo (sans). The site renders all text in HTML over the
  images, so **do not draw any letters/numbers**.

## Style language (apply verbatim)
- **Watercolor + ink linework.** Soft pigment washes with visible paper grain;
  loose, confident hand-drawn outlines in ink (`#2a2418`).
- **Calm, editorial, crafted.** Generous negative space. Balanced, unhurried.
- **Lighting:** soft, even, daylight. No dramatic shadows, no spotlight, no glow.
- **Texture:** the cream paper grain should read through the washes.
- **The signature feel:** a page from a well-loved garden journal.

## Hard "don'ts"
No text/letters/numbers/logos/watermarks · no photographs · no 3D · no glossy
gradients · no drop shadows · no UI elements/buttons/cursors · no neon · no
borders/frames unless the prompt asks · no brand logos of other companies.
