# ChatGPT Project — Description

**Project name:** nimrod.bio Visual System — איורי מים + משפחת לוגו (Stage 6)

**Purpose:** Generate the watercolor illustration system + logo family for the
**nimrod.bio** brand (נימרוד ולד) and its applications — continuing the existing,
hand-painted nimrod.bio illustration line by the original designer (Devora). The
brand has one root and three worlds — **אדמה** (Soil), **ידע / ייעוץ והוראה**
(Know), **דיגיטל / מיזו** (Code) — and the visual system serves all of them,
including **SFA** (the free community-farming AI, the digital world's flagship).

**Foundation:** the locked nimrod.bio AOS Design System (Taxonomy v3.4, brand
voice v2.1, master palette, typography, system.css) + the original Devora
watercolor masters (radishes, lettuce, dill, parsley, bunch, basket) + the Carmela
brand font. We extend this exact line — we do not invent a new style.

**House feeling:** real watercolor — washed stains, undefined edges, visible paper
texture, pigment pooling. Quiet, gentle, semi-abstract, handmade, analytical-warm.
Atmosphere over literal accuracy. Never digital-flat, never glossy AI watercolor,
never text inside the art.

**Scope (phased, per decisions D01–D10):** logo family + worlds hero backgrounds +
SFA module heroes + functional icons + OG/share + favicon + textures + empty states.

**How we work:** calibration-first. Lock the style on a small set against the Devora
masters, get approval, then produce family by family.
