# C1 — Brand Master (nimrod.bio)

**Root:** נימרוד ולד — farmer-practitioner, consultant, coder. "חוקר-מבצע שעובד
עם הידיים ועם הקוד באותה רמת כבוד." Warm, humble, analytical — NOT AI-startup-bro,
NOT organic-lifestyle-influencer, NOT big-agro.

**Three worlds + 4 bridges (Taxonomy v3.4 LOCKED):**
- **אדמה (Soil)** — "איפה שהאדמה פוגשת ידיים": produce for restaurants, hydroponic
  greenhouse, BCS field services, nursery; (legacy: family baskets 2019–23).
- **ידע (Know · UI label "ייעוץ והוראה")** — "איפה שהניסיון הופך לכלי": hydroponics
  consulting, agro/market-garden consulting, grow-planning, teaching.
- **דיגיטל / מיזו (Code)** — "איפה שהידע הופך למערכת חיה": **SFA** (P-07, free
  community AI for small farming — seed→seeking-partners), tiktrack, Sharon
  greenhouse co-op.
- **Bridges (the brand's uniqueness):** Soil×Know ("אין ייעוץ שלא נוסה בבוץ"),
  Know×Code, Soil×Code (the farm is the data source for SFA/tiktrack), Know×Know.

**Story:** "הגינה של נמרוד" eco-farm (2014, 1.2 dunam, 9 seasons) → deliberately
closed 2023 (scale change, not failure — "legacy", not "archived") → hydroponic
greenhouse + consulting + SFA. Moto: **"שורש אחד, שלוש זרועות."** Tagline:
**"העולם הוא כזה — אלא אם כן" (Unless).** Thesis: CDIP.

**Where SFA fits:** SFA is ONE application in the Code world. The SFA UI (sfa.nimrod.bio)
has its own `gj.css` tokens (a warmer variant); for SFA-specific assets you may use
those, but the **brand watercolor line + master palette (C2)** govern the family so
everything reads as one nimrod.bio hand.

**Master palette (system.css):** paper `#f5f3ec`, ink/earth `#5b483a`, soil-green
`#6a8a3a` (deep `#3a5220`), know-orange `#c46a3e` (deep `#9a4f2b`), code-teal
`#2d8a8c` (deep `#1f5e60`), spark-red `#d23a2e` (UI text accent, ≤5 uses, **not in art**).

**Typeface:** Carmela (Hebrew display, the wordmark) — see source_masters/font_carmela.
