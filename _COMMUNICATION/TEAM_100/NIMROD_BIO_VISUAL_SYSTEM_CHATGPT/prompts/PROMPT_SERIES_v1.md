# Prompt Series v1 — nimrod.bio / SFA watercolor image generation

Organized, numbered, copy-paste prompts. **Order is binding:** run Phase 0
(calibration) first, get Nimrod's approval, then production phases.

## Standing rules (apply to EVERY prompt below)
- **Attach the Devora reference images** to the session (radishes.png primary +
  lettuce/dill/parsley/bunch + basket). Each prompt already ends with the match-line.
- **Real watercolor only:** washed stains, feathered/undefined edges, visible
  transparent layers, pigment granulation, on cream paper `#f5f3ec` with paper grain.
  NOT digital, NOT flat, NOT glossy, NOT symmetrical, no clean vector outline.
- **Palette (illustrations):** olive `#6a8a3a`, earth `#5b483a`, tan-orange
  `#c46a3e`, dusty teal `#2d8a8c` (sparingly), cream `#f5f3ec`. **No bright red.**
- **No text, numbers, logos** inside any image. No photos, 3D, drop shadows.
- **Heroes:** keep one ~30% "quiet zone" (left or right) of near-empty paper for text.
- After generating: export per `context/C3` (sips/cwebp) to target dims/WebP budget;
  score on the QA rubric; save to `candidates/` (versioned).
- **Worlds heroes (5) + logo family** are NOT re-prompted here — use the locked
  `…/brand_system/nimrod_bio_AOS_design_system/01-PROMPT-watercolor-backgrounds.md`
  and `02-PROMPT-logo-family.md`.
