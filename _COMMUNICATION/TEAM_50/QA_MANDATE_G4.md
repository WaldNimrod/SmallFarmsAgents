### T05 — Data quality: aggregation consistency

```sql
-- min ≤ median ≤ max for all aggregates
SELECT COUNT(*) AS violations
FROM daily_aggregates
WHERE min_price > median_price
   OR median_price > max_price;
-- Must return 0

-- sample_size matches actual non-quarantined observations
-- NOTE: must be run immediately after run_aggregator with no concurrent ingestion
-- Filters match aggregator engine exactly: observed_at::date, market_scope, sales_channel, flag_status, is_quarantined
SELECT da.id, da.sample_size,
       COUNT(no.id) AS actual_count
FROM daily_aggregates da
JOIN normalized_observations no
     ON no.product_id = da.product_id
    AND (no.observed_at AT TIME ZONE 'UTC')::date = da.aggregate_date
    AND no.market_scope = da.market_scope
    AND (no.sales_channel = da.sales_channel
         OR (no.sales_channel IS NULL AND da.sales_channel IS NULL))
    AND no.flag_status = 'ok'
LEFT JOIN raw_extracted_items rei ON rei.id = no.raw_extracted_item_id
WHERE (rei.id IS NULL OR rei.is_quarantined IS NOT TRUE)
GROUP BY da.id, da.sample_size
HAVING da.sample_size != COUNT(no.id);
-- Must return 0 rows
```

**Pass criterion:** Both queries return 0 rows/violations.

### T09 — Regression: M1–M3 tables unmodified

Run the following SQL to verify M1–M3 tables are unchanged by M4:

```sql
-- Structural invariants (must match exactly):
SELECT 'sources' AS tbl, COUNT(*) AS n FROM sources
UNION ALL SELECT 'products', COUNT(*) FROM products
UNION ALL SELECT 'product_aliases_active', COUNT(*) FROM product_aliases WHERE is_active=true;
-- Expected: sources=20, products=29, product_aliases_active=97

-- Append-only tables (must not decrease):
SELECT 'raw_extracted_items_gte_3000' AS check,
       (COUNT(*) >= 3000)::text AS pass FROM raw_extracted_items;
SELECT 'normalized_observations_gte_300' AS check,
       (COUNT(*) >= 300)::text AS pass FROM normalized_observations;
-- Both must return 'true'
```

**Baseline** (set by migrations 001–013, before any M4 pipeline run):

| Table | Expected count |
|-------|---------------|
| sources | 20 |
| products | 29 |
| product_aliases (active) | 97 |
| raw_extracted_items | ≥ 3,000 (append-only) |
| normalized_observations | ≥ 300 (append-only) |

Note: `raw_extracted_items` and `normalized_observations` are append-only — they
grow with ingestion/normalization. The regression criterion is that they do **not
decrease** and the fixed-set tables (sources, products, aliases) are **unchanged**.

M4 pipeline writes only to `daily_aggregates`, `weekly_snapshots`, and
`output/public/` — it does not modify any M1–M3 table.

**Pass criterion:** `sources=20`, `products=29`, `product_aliases_active=97`, and
both append-only checks return `true`.
