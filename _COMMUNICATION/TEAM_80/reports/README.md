# Team 80 reports — scope (SmallFarmsAgents repository)

Files in this directory, **when committed in this git repository**, must concern **OrganicMarketAgent (SFA)** product strategy, research, and handoffs for the **price index** (see `sfa_handoff_v2/`, `smallfarms_agent_handoff/`).

**Do not** commit primary deliverables for other MyFarmAgents products (e.g. **Famely Neusletter**, TikTrack, agents-os dashboards) here. Those belong in **their own repositories** or in **machine-level** coordination (`~/Documents/_agent_comm/`), not mixed into SFA version control.

If a session in Cursor is opened on **SmallFarmsAgents**, treat the **default product scope** as **SFA only** unless Nimrod or a mandate explicitly expands it.

See also: [`documentation/external-references/CROSS_PROJECT_BOUNDARIES.md`](../../../documentation/external-references/CROSS_PROJECT_BOUNDARIES.md).
