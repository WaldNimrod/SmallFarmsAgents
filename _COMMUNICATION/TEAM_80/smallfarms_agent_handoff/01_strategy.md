# Strategy

## Core Shift
From: story-first page  
To: **tool-first page with context before and after**

## Content Order Principle
1. Problem clarity (short)
2. Immediate access to tool (visible early)
3. Minimal explanation
4. Invitation to participate
5. Credibility (about + AI layer)
6. Link to full story (blog)

## Key Messaging
- This already works
- Based on real data
- You can use it now
- You can help improve it

## Audience
- Small farmers
- Ecological / community agriculture
- Early adopters of collaborative tools

## Differentiation
- Built by someone who **actually farmed + built systems**
- Not SaaS — evolving ecosystem
