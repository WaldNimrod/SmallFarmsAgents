# UI Specification

## Principles
- Immediate usability
- No login required
- Clear numbers
- Minimal friction

## Table Requirements
- Editable cells
- Default values from dataset
- Realtime calculation

## Visual Priority
1. Table
2. Crop selector
3. Results

## Micro UX
- Highlight changed values
- Show cost breakdown clearly
- Avoid clutter

## Responsive
- Mobile-friendly table (stacked or scrollable)
